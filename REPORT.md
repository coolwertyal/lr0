1. Зачем запускать приложение в контейнере от непривилегированного пользователя?
	#Если запуск идёт от root, то при взломе через уязвимостьатакующий получает root права внутри контейнера. Это даёт ему возможность выйти из контейнера на Хост. appuser не моет менять системные файлы и ставить новые пакеты. 'Принцип наименьших привелегий'исходя  из теории. 
2. Почему порт Redis не публикуется наружу?
	#К Redis обращается только контейнер Web, они общаются по сети docker compose по имени redis. Публикация порта открыла бы базу всем appuser в сети, а у redis нет пароля по умолчанию. Поэтому порт публикуется только в web.
3. Чем открытый SSH-ключ отличается от закрытого и что из них можно отправлять другим?
	#Закрытый id_ed..... хранится только у владельца и подтверждает личность user, открытый id_ed....9.pub служит для проверки. Другим можно отправлять открытый. Закрытый нельзя любой сможет войти от Моего Юзера.


2. **WORKDIR /app**: Этот ряд создает папку `/app` в нашем Docker-образе, где можно будет хранить приложение.

3. **COPY requirements.txt .**: Этот ряд копирует файл `requirements.txt` в папку `/app`, который содержит список
зависимостей нашего приложения. Это необходимо для установки зависимостей при создании Docker-образа.
